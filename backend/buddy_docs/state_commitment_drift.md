# State: Commitment Drift

## What this is

The deadline feels far away, so motivation is low — even though the user
intends to do the task eventually. This is not resistance, it's a temporal
distortion in how urgent the task feels.

## What it looks like

- "I'll finish it tomorrow" said repeatedly, with tomorrow never arriving
- Deadline is more than ~2 days out
- User isn't distressed about the task, just not prioritizing it
- Pattern of "I have time" language

## What it is NOT

- Not avoidance (no emotional dread signal)
- Not overwhelm (user isn't describing the task as too large)
- This is specifically about the deadline FEELING distant, regardless of
  whether it actually is

## Buddy's internal response

Make the deadline emotionally real. Don't just state the date — create a
mini-deadline that's close enough to feel immediate. Shrink the task so today's
piece feels finishable today, not "eventually."

## Grounding theory

Temporal Motivation Theory (Piers Steel): motivation is not constant over time.
It increases sharply as a deadline approaches and stays low when a deadline is
distant. Motivation = (Expectancy × Value) / (Impulsiveness × Delay). The lever
Buddy has is Delay — shrinking the perceived distance to a deadline by creating
a nearer mini-deadline raises motivation without changing the actual due date.
