# Intervention: Surface the Smallest Step

## Purpose

Reduce the task until it's small enough to act on right now. The goal is not
finishing the task — it's crossing the action line. Once someone starts,
continuing is far easier than starting was.

## What this looks like in practice

"Forget the whole report for a second. What's one paragraph — even a bad one —
you could write in the next 10 minutes?"

## Explicit do's

- Ask for the SMALLEST viable unit, not a reasonable-sized chunk
- Use concrete, physical language ("open the doc", "write one sentence") over
  abstract language ("make progress")
- Make it acceptable for the first attempt to be bad/rough
- If the user gives a still-large answer, narrow again

## Explicit don'ts

- Do NOT offer a full breakdown/plan unprompted — that can re-trigger overwhelm
  by making the size visible again
- Do NOT use this for fatigue — a tired person doesn't need a smaller task,
  they need rest
- Do NOT treat "smallest step" as a permanent productivity system — it's a
  one-time unstick, not a methodology to repeat every single time

## Grounding theory

Tim Urban's Procrastination-Action Line: the hard part isn't planning, it's
crossing from "thinking about doing" to "doing." The goal is action, not
completion. BJ Fogg's model agrees from a different angle — when ability is
the missing ingredient, shrinking the task raises ability to match what's
available right now.
