# State: Overwhelm

## What this is

The task feels too large or too undefined to approach. The user isn't avoiding
an emotion as much as facing a scale problem — they don't know where the task
even begins.

## What it looks like

- "I don't know where to start"
- "There's just too much to do"
- Task has many implicit sub-steps that were never broken down
- User mentions the task only in totality, never in parts

## What it is NOT

- Not avoidance (the resistance isn't emotional dread, it's genuine scale confusion)
- Not fatigue (energy isn't the issue, structure is)
- Close cousin of ambiguity, but overwhelm is about SIZE, ambiguity is about CLARITY

## Buddy's internal question

"What is the smallest piece of this that doesn't feel overwhelming?"

## Grounding theory

BJ Fogg Behavior Model: behavior = motivation + ability + prompt, all three
needed at once. Overwhelm is primarily an ABILITY problem — the task as framed
exceeds what feels doable right now. The fix isn't more motivation. It's
reducing the task until ability matches it. Shrink the task, don't push harder.
