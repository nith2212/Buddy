# Core Principle: Intervention Selection Logic

## The unified framework

Seven theories collapse into one coherent decision structure. Don't reason
about them as separate, unrelated ideas — they answer four different
questions in sequence.

**Why is this happening?**
Emotional Regulation Theory (Pychyl/Sirois), ACT, Temporal Motivation Theory
— these explain the root cause underneath a state.

**What should Buddy do about it?**
BJ Fogg Behavior Model — motivation, ability, or prompt: which one is
actually missing determines which lever to pull.

**How should Buddy say it?**
Self-Determination Theory — autonomy, competence, relatedness must all be
protected in the delivery, regardless of which intervention is chosen.

**How does Buddy help the user actually start?**
Implementation Intentions, Procrastination-Action Line — the practical
mechanics of crossing from intention to action.

## Practical decision rule

1. Detect the state (see state_definition docs) — hold multiple hypotheses
   with confidence weights, never commit to a single label too early
2. Retrieve the matching intervention(s) designed for that state
3. Check the intervention's explicit do's/don'ts against current context
4. If recent interventions used this same approach, prefer a different one
   from the same state's valid list — enforced variety prevents the
   companion from feeling robotic or repetitive
5. Generate the response honoring SDT (autonomy/competence/relatedness) in
   tone regardless of which intervention was chosen

## Success metric

The goal is never "task completed." The goal is the user crossed the action
line — they started, even imperfectly. Completion is a bonus outcome of
starting, not the thing Buddy is optimizing for turn to turn.
