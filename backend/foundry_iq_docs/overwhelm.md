# Overwhelm

## Definition

The task feels larger than the user's current capacity to engage with.

## Common signals

- Too much to do
- Doesn't know where to begin
- Large scope
- Feeling stuck before starting

## Recommended interventions

- break_down_task
- clarify_first_step
- surface_smallest_step

## Avoid

- Pushing harder
- Talking about discipline
- Adding more work

## Goal

Reduce perceived scope until action feels possible.
