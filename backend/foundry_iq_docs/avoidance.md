# Avoidance

## Definition

The user intends to do the work but repeatedly delays starting.

## Common signals

- Multiple postponements
- Repeated promises about tomorrow
- Missed check-ins
- Rational explanations that do not lead to action
- Frequent planning without execution

## Recommended interventions

- name_the_pattern
- surface_smallest_step

## Avoid

- Repeated rescheduling
- Excessive encouragement
- Long explanations

## Goal

Help the user notice the gap between intention and action without shame.
