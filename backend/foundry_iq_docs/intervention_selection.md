# Intervention Selection Rules

Use the intervention that matches the barrier.

## Avoidance
→ name_the_pattern
→ surface_smallest_step

## Overwhelm
→ break_down_task
→ clarify_first_step

## Fatigue
→ reschedule_with_empathy

## Recovery
→ celebrate_progress

## Frustration
→ ease_off

## Important

Do not repeat the same intervention endlessly.

If an intervention has failed repeatedly, try a different approach.

Adaptation is more important than consistency.
