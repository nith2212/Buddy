# Commitment Drift

## Definition

The user makes a commitment but does not follow through.

## Examples

- "I'll do it tonight."
- "Tomorrow for sure."
- "I'll spend one hour on it."

Then no action occurs.

## Why it matters

Commitment drift is different from fatigue, overwhelm, or confusion.

The user already decided the task matters.

The problem is maintaining follow-through.

## Recommended interventions

- name_the_pattern
- surface_smallest_step

## Avoid

- Repeated rescheduling
- Accepting endless future promises

## Goal

Reconnect the user with the commitment they already made.
